# Словарь терминов интерфейса (ru · uz-Latn · en)

> **Все термины требуют проверки МИГ.** Переводы подготовлены без носителя языка и без юриста по страхованию. Пока МИГ их не подтвердит, интерфейс использует их как рабочие.

Правила:

- В интерфейсе термины используются **строго по этому словарю**. Новый термин сначала попадает сюда, потом в словари `src/i18n/dict/*`.
- Узбекский пишется латиницей по действующей орфографии. Для oʻ и gʻ используется знак ʻ (U+02BB), для твёрдого знака — ʼ (U+02BC). ASCII-апостроф (') и типографские кавычки (’ ‘) запрещены, это проверяет тест.
- Склонение и регистр подстраиваются под фразу, но корень термина менять нельзя: «полис» → «polis», «polisni», «polislar».
- Колонка «Уверенность»: **?** — термин требует особого внимания при проверке (варианты в примечании).
